Erstelle den Wochenrückblick:

1. git log der letzten 7 Tage: Was wurde gebaut (nach Abenden gruppiert)?
2. Abgleich mit BAUPLAN.md/BAUPLAN2.md: Was ist fertig, was offen? Welche
   Abnahmen und Handy-/Feld-Checks stehen aus?
3. Ehrliche Einschätzung: Wo wurde gebaut ohne Abnahme? Wo droht die
   Migrationsregel (ein Modul aufs Mal führend) zu kippen?
4. Plan nächste Woche: maximal 3 konkrete Punkte, Prüfungen vor Neubau.
5. Hänge eine Kurzfassung (5 Zeilen, mit Datum) an WOCHENLOG.md an
   (Datei anlegen, falls fehlt). Nichts anderes ändern.
